# Part 1: Relational Database ETL Pipeline

This module implements an end-to-end ETL pipeline for FlexiMart using Python and MySQL.

## What this part covers
- Reading raw CSV files (customers, products, sales)
- Data cleaning and transformation using pandas
- Loading cleaned data into MySQL tables
- Generating a data quality report

## Files
- etl_pipeline.py – Main ETL script
- data_quality_report.txt – Summary of duplicates and null handling
- requirements.txt – Python dependencies

## Output
- Cleaned data loaded into MySQL database `fleximart`
- Data quality report generated automatically
